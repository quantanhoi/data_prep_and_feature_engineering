# Untidy Data Mock Exam

## Overview
This exam tests your ability to identify and fix untidy data issues. You will work with multiple datasets that violate the principles of tidy data.

## Learning Objectives
- Identify different types of untidy data patterns
- Apply appropriate transformation techniques to convert untidy data to tidy format
- Work with both CSV and JSON data sources
- Handle complex data structures (nested arrays, wide-format data, etc.)

## Tasks
You will encounter 4 different untidy data scenarios:

1. **CSV Dataset 1**: Sales data with multiple variables in column headers
2. **CSV Dataset 2**: Multiple variables stored in one column
3. **JSON Dataset**: Nested arrays that need to be exploded
4. **CSV Dataset 3**: Multiple observational units in the same table

## Files
- `untidy_data_exam.ipynb` - Main exam notebook with tasks
- `hints.md` - Hints for each task (check this if you're stuck)
- `solution.py` - Complete solution (don't peek until you've tried!)
- `ANSWER_KEY.md` - Detailed explanations of untidy data types
- `data/` - Contains all datasets

## Time Estimate
45-60 minutes

## Getting Started
1. Open `untidy_data_exam.ipynb`
2. Read each task carefully
3. Identify the type of untidy data
4. Write transformation code to convert to tidy format
5. Verify your results

## Tidy Data Principles (Review)
Tidy data has:
1. Each variable forms a column
2. Each observation forms a row
3. Each type of observational unit forms a table
